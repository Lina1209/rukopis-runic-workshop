# Рукопись — виртуальная мастерская рунического письма

Добро пожаловать в проект «Рукопись»!

Это виртуальная мастерская для изучения и написания древних систем письма.

## Рунические системы

- Старший футарк
- Англосаксонские руны
- Исландские рунические ряды
- Руны Ведьм
- Огам

## Возможности

- Виртуальная клавиатура
- Работа с руническими шрифтами
- Написание и преобразование текстов
- Копирование и сохранение результатов
- Экспорт изображений PNG
